# 緊急警報信号 (EWS) 技術仕様まとめ — 一次資料の転記

本プロジェクトの実装はすべて以下の一次資料に基づく。数値・符号は原典から
転記したものであり、推測を含まない。

## 一次資料

1. **無線設備規則** (昭和25年電波監理委員会規則第18号) **第9条の3**
   「緊急警報信号発生装置」
   - 総務省 電波法令検索: https://www.tele.soumu.go.jp/horei/law_honbun/72081000.html
2. **昭和60年郵政省告示第405号**
   「無線設備規則第九条の三第五号の規定に基づく緊急警報信号の構成」(昭和60年6月1日)
   - 総務省 電波法令検索: https://www.tele.soumu.go.jp/horei/law_honbun/72103000.html
3. 伊藤泰宏 (NHK放送技術研究所)「緊急警報放送」
   映像情報メディア学会誌 Vol.61, No.6, pp.761-763 (2007) — 解説記事
   - J-Stage: https://www.jstage.jst.go.jp/article/itej/61/6/61_6_761/_pdf

## 変調仕様 (無線設備規則 第9条の3)

| 項目 | 規定 |
|---|---|
| 変調方式 | 周波数偏位方式 (FSK) |
| マーク周波数 ("1") | 1,024 Hz (許容偏差 ±10ppm) |
| スペース周波数 ("0") | 640 Hz (許容偏差 ±10ppm) |
| 位相 | 周波数偏位時において連続 (連続位相FSK) |
| 伝送速度 | 毎秒64ビット (許容偏差 ±10ppm) |
| 歪率 | 5%以下 |
| 構成 | 別に告示 (→ 告示第405号) |

1ビット = 15.625ms は 640Hz のちょうど10周期・1024Hz のちょうど16周期に
あたるため、各ビット境界で位相が一致し、クリックのない連続波形になる。

## 信号構成 (告示第405号 第1項・第2項)

### 第一種開始信号・第二種開始信号

```
[無信号期間 1秒間以上]
[前置符号4][固定16][地域区分16][固定16][月日区分16][固定16][年時区分16] ← 1ブロック=100ビット(1.5625秒)
(ブロックを4以上連接。中波放送・短波放送では10以上)
```

注: 告示の構成図では「96ビット」の寸法線は前置符号を除いた6符号分を指す。
1ブロックの実長は前置符号4ビットを含む100ビット。

### 終了信号

```
[無信号期間 1秒間以上]
[前置符号4][固定16][地域区分16][固定16][月日区分16][固定16][年時区分16][無信号期間92ビット] ← 1ブロック=192ビット(3.0秒)
(ブロックを2以上連接。中波放送・短波放送では4以上)
```

## 符号の構成 (告示第405号 第3項)

| 符号 | 種別 | 構成 |
|---|---|---|
| 前置符号 (4bit) | 第一種・第二種開始 | `1100` |
| | 終了 | `0011` |
| 固定符号 (16bit) | 第一種開始・終了 | `0000 1110 0110 1101` |
| | 第二種開始 | `1111 0001 1001 0010` (第一種の全ビット反転) |
| 地域区分符号 (16bit) | 開始 | `10` + [地域符号12bit] + `00` |
| | 終了 | `01` + [地域符号12bit] + `11` |
| 月日区分符号 (16bit) | 開始 | `010` + [日符号5bit] + ※ + [月符号5bit] + `00` |
| | 終了 | `100` + [日符号5bit] + ※ + [月符号5bit] + `11` |
| 年時区分符号 (16bit) | 開始 | `011` + [時符号5bit] + ※ + [年符号5bit] + `00` |
| | 終了 | `101` + [時符号5bit] + ※ + [年符号5bit] + `11` |

### ※ビットと偶数ブロックの日時 (告示 注1・注2)

- **奇数番目のブロック**は常に信号送出の日・時。※=0。
- **偶数番目のブロック**:
  - 月日 (注1): 0:00〜0:10未満は**前日**、23:50〜24:00未満は**翌日**、それ以外は送出日
  - 年時 (注2): 毎時0分〜10分未満は**前の時**、毎時50分〜60分未満は**次の時**、それ以外は送出時
  - 符号が送出の日・時に対応する場合 ※=0、前後の日・時の場合 ※=1

受信機の時計と数分の誤差があっても日時照合ができるようにする仕組みで、
電波妨害による受信機の不要動作対策に使われる (解説記事 p.762)。

## 別表 (告示第405号)

### 別表第1号 地域符号 (12ビット・全53符号)

実装の完全な表は [`src/ews/area-codes.js`](../src/ews/area-codes.js) を参照。
地域共通 `001101001101`、広域5符号 (関東・中京・近畿・鳥取島根・岡山香川)、
県域47符号。全符号がハミング重み6の定重み符号で、任意の2符号間の
ハミング距離は4以上 (テストで検証)。

この12ビット表は ISDB (ARIB STD-B10 第2部 付録D 表D-2) の
`area_code` と同一である。

### 別表第2号〜第5号 (日・月・時・年符号、各5ビット)

いずれも「値の最下位ビットを先に送る」LSBファースト構成
(**単純な2進表現とはビット順が逆**であることに注意):

| 表 | 値 | 例 |
|---|---|---|
| 日符号 | 日(1〜31)のLSBファースト5bit | 1日=`10000`, 16日=`00001`, 31日=`11111` |
| 月符号 | 月(1〜12)のLSBファースト4bit + `1` | 1月=`10001`, 12月=`00111` |
| 時符号 | (時 mod 8) + 8×(3−⌊時/8⌋) のLSBファースト5bit | 0時=`00011`, 23時=`11110` |
| 年符号 | 西暦下1桁(0は10と読替) + 16 のLSBファースト5bit | 1985年=`10101`, 1990年=`01011` |

年符号は昭和60年(1985)〜昭和69年(1994)の10符号が定められ、以後は
「順次繰り返して使用する」(別表第5号 注)。つまり**年符号が伝えるのは
西暦の下1桁のみ**で、10年周期で同じ符号になる。

## 運用に関する参考事項 (解説記事より)

- 緊急警報放送が行われるのは次の3つの場合に限られる (p.762):
  1. 大規模地震の警戒宣言 → 第一種開始信号
  2. 津波警報 → **第二種開始信号**
  3. 都道府県知事からの放送要請 → 第一種開始信号
- 第二種信号は、津波の来ない高台の住民が自動起動をオフに設定できる
  ようにするための区別 (p.762)。
- 受信機は、自機に設定された県域の符号・対応する広域符号・地域共通符号の
  いずれかを受信したときだけ自動的にスイッチONになる (p.762 の館山の例)。
- NHKは毎月1日の正午前に試験信号を放送している (2007年時点, p.761)。
- デジタル放送ではこの音声FSK信号ではなく、TMCCの起動フラグ (送出周期0.2秒)
  とPMTの緊急情報記述子で伝送される (p.763)。緊急情報記述子の地域符号は
  本ツールの12ビット表と同一。
